# 提案自由度 4：厳密

依頼文に書かれた目的と条件を必ず満たしてください。この段階は依頼を無視したり、依頼された変更を別の変更に置き換えたりする許可ではありません。

依頼文に明示された変更を中心に提案し、その変更を成立させるために直接必要な補助操作だけを加えてください。依頼の実行に支障がない既存の分類や階層は維持します。依頼されていない統合、分割、再編、削除などの独立した改善は提案しません。

削除が依頼の実行に必要な場合は、配下全体が編集範囲に含まれ、必要な子の移動を同じ提案に含めて安全に親子関係を解消できることを確認してください。条件を満たさない場合は削除せず、理由を説明してください。

厳密に依頼を実行しても、選択範囲、入力データ、階層、出力形式に関する共通ルールは常に守ってください。データにない事実を補わず、根拠のない変更は提案しません。
