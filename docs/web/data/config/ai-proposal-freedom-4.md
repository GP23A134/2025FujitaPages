# 提案自由度 4：厳密

依頼文に明示された変更を中心に扱い、それを成立させるため直接必要な補助操作だけを加えてください。依頼の実行に支障がない既存の分類や階層を維持し、依頼されていない統合、分割、再編、削除などの独立した改善は提案しません。

依頼の意図や移動先に複数の解釈が残る場合でも、入力中に候補となる移動先が一つでもあり、依頼された変更範囲に含まれるなら、その候補への暫定案を提示して前提と不確実性を明記してください。複数候補がある場合は候補先ごとの案を示します。入力から移動先候補を特定できない場合や、依頼の対象自体が特定できない場合は確認してください。依頼されていない独立した改善は追加しません。

削除は依頼の実行に必要な場合に限ります。配下全体が編集範囲に含まれ、必要な子の移動を同じ提案に含めて安全に親子関係を解消できることを確認してください。条件を満たさない場合は削除せず、理由を説明します。
