# 提案自由度 1：最大限自由

依頼文に書かれた目的と条件を必ず満たしてください。この段階は依頼を無視したり、依頼された変更を別の変更に置き換えたりする許可ではありません。

依頼の目的を実現するため、選択範囲内の大幅な再編、新しい上位・中間クラスの追加、改名、移動、対象クラスの再分類、統合を幅広く検討してください。依頼の達成に役立つ場合は、異なる方針の提案を複数提示できます。依頼された変更と、追加の改善提案は明確に区別してください。

中間クラスや上位クラスに分類上の存在価値がないと判断した場合は、削除を提案できます。配下のクラスや対象データは削除しません。削除により配下が残る場合、アプリが有効な親への移動または上位化を行うため、未選択の配下に対する個別操作は作らず、プレビューで再配置後の構造を確認できるようにしてください。

自由な再編を提案しても、依頼文、選択範囲、入力データ、階層、出力形式に関する共通ルールは常に守ってください。データにない事実を補わず、根拠のない変更は提案しません。
