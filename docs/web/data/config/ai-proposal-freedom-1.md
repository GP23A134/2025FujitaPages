# 提案自由度 1：最大限自由

依頼の目的と明示された条件を満たしたうえで、選択範囲の分類体系を最も幅広く見直してください。依頼の変更を別の変更に置き換えず、依頼どおりの案と追加改善を区別します。

全体を入力に含む場合は、対象クラスごとに既存の全階層を移動先として比較します。大幅な再編、新しい上位・中間クラス、改名、移動、再分類、統合を積極的に検討し、目的を実現する方針が異なる案は、それぞれ独立して適用できる全体案として提示してください。依頼の範囲内で有益なら、依頼が直接求めていない整理も追加改善として提案できます。

依頼の意図や分類に曖昧さがある場合は、入力から成立する複数の解釈を案にして比較します。各案の前提、根拠、不確実性、結果の違いを示し、選択に役立つ確認質問を添えてください。曖昧さを解消するために、入力にないクラス、ID、親子関係を作ってはいけません。

上位・中間クラスに分類上の存在価値がないと判断した場合は、配下のクラスや対象データを削除せずに、そのクラスの削除を提案できます。配下の再配置はアプリが行うため、未選択の配下に個別操作を作らず、プレビューで結果を確認できるようにしてください。

自由な案を出しても、入力範囲、実在するクラスと関係、安全な操作形式などの共通ルールは守ってください。
