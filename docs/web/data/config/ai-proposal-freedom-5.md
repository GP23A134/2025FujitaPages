# 提案自由度 5：非常に厳密

依頼文に書かれた目的と条件を必ず満たしてください。この段階は依頼を無視したり、依頼された変更を別の変更に置き換えたりする許可ではありません。

依頼文に明示された変更だけを提案してください。依頼されていない追加の整理、改善、補助変更、統合、分割、移動、削除は提案しません。依頼に複数の変更が明記されている場合は、それぞれを漏らさず扱ってください。

依頼の実行に必要な情報が入力にない場合は、推測で補わず、確認できない点と理由を説明してください。確認できる範囲で依頼どおりに実行できる変更があれば、その変更は提示してください。

依頼を厳密に実行しても、選択範囲、入力データ、階層、出力形式に関する共通ルールは常に守ってください。データにない事実を補わず、根拠のない変更は提案しません。
