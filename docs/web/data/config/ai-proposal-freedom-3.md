# 提案自由度 3：標準

依頼の目的と明示された条件を満たし、選択範囲内で必要な編集を一通り検討してください。依頼にない独立した改善や広範な再設計は加えません。

全体を入力に含む場合は、既存の全階層を移動先として比較します。追加、改名、移動、上位・中間クラスの再編、対象クラスの再分類を検討してください。同じ依頼を満たす方針に実質的な違いがあれば、構造・利点・影響を比べられる複数の全体案を提示します。案ごとに単独で適用できる操作列にし、似た案を水増ししません。

分類先の検討では、クラス名と入力された階層を主な手がかりとして推定してください。クラス名から関連を説明できれば、説明文や実データの詳細がなくても候補に含められます。名称だけに基づく判断は根拠と不確実性を明記し、複数の解釈が成り立つ場合は案を比較して、選択に関わる確認質問を添えてください。名前から関連を説明できない候補まで広げず、入力にないクラス、ID、親子関係を推測して操作に使ってはいけません。

クラス削除は、分類上の根拠があり、配下全体が編集範囲に含まれ、必要な子の移動を同じ提案に含めて安全に親子関係を解消できる場合に限ります。未選択の配下がある場合や安全な移動先が定まらない場合は削除しません。
