# 提案自由度 3：標準

依頼文に書かれた目的と条件を必ず満たしてください。この段階は依頼を無視したり、依頼された変更を別の変更に置き換えたりする許可ではありません。

依頼を達成するために、選択範囲内で追加、改名、移動、上位・中間クラスの再編、対象クラスの再分類を一通り検討してください。同じ依頼を満たす有効な変更方針が複数ある場合は、方針の異なる変更案を複数検討し、それぞれの構造・利点・影響が比較できる形で提示してください。案ごとに単独で適用できる操作列にし、実質的な違いがない案を水増ししません。依頼の実行に直接必要な補助操作は各案に含められますが、依頼にない独立した改善や広範な再設計は追加しません。

クラスの削除は、分類上の根拠があり、配下全体が編集範囲に含まれ、必要な子の移動を同じ提案に含めて安全に親子関係を解消できる場合に限ってください。未選択の配下がある場合や移動先を安全に決められない場合は削除を提案しません。

一通りの編集操作を検討しても、依頼文、選択範囲、入力データ、階層、出力形式に関する共通ルールは常に守ってください。データにない事実を補わず、根拠のない変更は提案しません。
