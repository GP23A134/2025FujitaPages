# 共通処理

閲覧画面と編集画面で共用する階層ツリー、データ取り込み、作業データ保存の処理です。ページ固有の表示や編集操作は各画面のフォルダに置きます。

## ファイル

| ファイル | 担当 |
| --- | --- |
| `tree.js` | 階層モデル、ツリー描画、対象クラスの行配置、展開位置の保持など共通関数 |
| `data-upload.js` | JSON取り込み、参照・循環の検証、作業データへの追加・置換 |
| `data-workspace.js` | IndexedDBへの作業データと取り消し履歴の保存 |

## データ取り込み

取り込みは最大2ファイル、合計50MBまでです。親子関係の重複、参照先不在、循環などの不正な階層は読み込み時に拒否します。

## 読み込み方

`index.html`と`edit.html`で画面別スクリプトより先に読み込みます。共通関数は通常のブラウザースクリプトから使えるよう`window`に公開します。

閲覧・編集のツリーDOMはこのモジュールで共通化し、各画面のモジュールが検索結果、操作ボタン、選択表示を追加します。階層線やカードの見た目は`web/css/tree-structure.css`と`web/css/tree-appearance.css`で調整します。
