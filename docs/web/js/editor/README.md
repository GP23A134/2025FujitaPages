# 編集画面

`edit.html`で使う編集状態、保持パネル、ツリー操作、保存、画面イベントを担当します。AI機能は`ai/`に分離しています。

## ファイル

| ファイル | 担当 |
| --- | --- |
| `state.js` | 編集データ、選択状態、共通の編集操作 |
| `panels.js` | 保持パネルと選択中クラスの操作 |
| `tree.js` | 編集用ツリー、検索、件数絞り込み |
| `events.js` | 保存、Undo/Redo、画面イベントとAI向けデータAPI |
| `ai/` | AI相談、API通信、応答検証、提案プレビュー |

## 読み込み順

`edit.html`は`shared/tree.js`の後に`state.js`、`panels.js`、`tree.js`、`events.js`を読み込みます。AIは`ai/main.js`をES moduleの入口として読み込みます。詳しくは[AIモジュールのREADME](ai/)を参照してください。

## 編集画面の操作

- 保持パネルで選択した対象やクラスを、既存の上位・中間クラスへ移動できます。上位・中間クラスの追加・改名・削除は編集ツリーで行います。最上位の「上位クラスを追加」行は階層項目ではないため、点と接続線を表示しません。
- ツリーの行をドラッグし、上位・中間クラスへドロップすると移動できます。複数選択中の行なら選択項目をまとめて移動し、未選択の行ならその項目と配下を移動します。タッチ画面では長押しでドラッグを始めます。循環する移動は既存の検証で拒否します。
- ツリー検索は閲覧画面と同じクラス／インスタンス検索、色分けしたキーワードチップ、件数条件を使います。Enterで語句を確定し、チップは個別に解除できます。条件に一致した対象クラスをまとめて選択・解除できます。
- AIチャットの設定は保持欄ヘッダーの履歴ボタン横にある歯車から開きます。APIキー、モデル、回答モード、提案自由度、リクエスト処理、送信前確認はAIチャット設定にまとめています。チャット、上位・中間・対象クラス、提案、保持欄の文字サイズは「データ追加」の隣にある「表示設定」から調整できます。
- AIチャット設定で提案の自由度を5段階に調整できます。1は大幅な再編や複数方針の案を幅広く検討し、価値のない上位・中間クラスの削除も提案します。2は依頼に関連する補助変更、3は標準的な編集操作と曖昧な意図に対する複数の解釈案を検討します。1〜3では、依頼の意図が曖昧でも入力に根拠のある案を不確実性とともに提示します。移動先の探索範囲は自由度によらず「候補の検索方法」の設定に従います。4は明示された変更と直接必要な補助操作に絞り、5は明示された変更だけを扱います。レベル1で配下が残るクラスを削除する場合、配下は削除せず別の有効な親へ移動または上位化し、プレビューで確認できます。設定はブラウザーに保存し、入力範囲・安全性・出力形式の必須ルールは変えません。
- 保存は全件のクラス一覧と親子関係をJSONで出力します。AI提案はプレビューで操作を確認し、利用者が適用した時点で編集状態に反映します。
