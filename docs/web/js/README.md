# JavaScript構成

`web/js`には、閲覧画面と編集画面で使うブラウザー側の処理を置きます。画面ごとの処理は`browse/`と`editor/`に分け、両方で使う階層ツリーの処理は`shared/`にまとめています。

## フォルダー

| パス | 役割 |
| --- | --- |
| `shared/tree.js` | 閲覧・編集画面で共用する階層モデル、ツリー描画、検索処理 |
| `browse/` | 閲覧画面の初期化、ツリー・一覧の表示、集計、検索や絞り込み |
| `editor/` | 編集画面の状態管理、保持パネル、ツリー編集、保存とイベント |
| `editor/ai/` | AI相談、送信データ計画、API通信、応答検証、提案の表示と適用 |

## 読み込み方

- `index.html`は`shared/tree.js`の後に`browse/`のスクリプトを読み込みます。`bootstrap.js`が画面要素と共通状態を初期化し、後続モジュールがそれを使います。
- `edit.html`は`shared/tree.js`の後に`editor/`のスクリプトを読み込みます。`state.js`が編集状態と共通操作を準備し、パネル・ツリー・イベントの各モジュールが順に利用します。
- 閲覧・編集画面の従来スクリプトは通常のスクリプトとしてHTMLに記載した順で動きます。依存関係があるため、読み込み順を変える場合は参照先も確認してください。
- AI機能は`edit.html`から`editor/ai/main.js`だけをES moduleとして読み込みます。`main.js`が同じフォルダーの機能モジュールを`import`します。

## データと変更の流れ

閲覧画面はクラスデータを表示・集計します。編集画面の状態と編集可能な操作は`editor/state.js`が管理し、保存や画面イベントは`editor/events.js`が扱います。AIは編集候補を返すだけで、応答を検証してプレビューに表示します。編集データへの反映は利用者が提案を適用したときに行います。

閲覧・編集の検索欄はクラス／インスタンス検索と件数条件を持ち、Enterで検索語をチップとして確定します。選択したチップは個別に解除できます。閲覧画面にはツリーの一括展開と対象クラス表示の切り替えがあり、編集画面では検索条件に一致した対象の選択・解除もできます。詳しくは[閲覧画面README](browse/)と[編集画面README](editor/)を参照してください。

HTMLの`<script>`と`<link>`、ES moduleの`import`にはキャッシュ更新用の`?v=`が付いています。JavaScriptやCSSを変更して公開する際は、参照元のバージョン文字列も更新してください。
