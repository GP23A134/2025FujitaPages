# 閲覧画面

`index.html`で使う閲覧機能です。画面初期化、一覧、ツリー、検索、集計を担当します。

## ファイル

| ファイル | 担当 |
| --- | --- |
| `bootstrap.js` | DOM参照と後続スクリプトが使う状態の初期化 |
| `lists.js` | クラス・インスタンス一覧の描画 |
| `aggregation.js` | 件数・分布・重複・関係整合性の集計と表示 |
| `tree.js` | 閲覧用ツリーデータ、検索、展開 |
| `main.js` | 初回描画とタブ・検索・絞り込みイベント |

## 読み込み順

`index.html`は`shared/tree.js`の後に`bootstrap.js`、一覧・集計・ツリーの各ファイル、最後に`main.js`を読み込みます。後続ファイルは初期化済みのDOM参照や共通関数を使います。
