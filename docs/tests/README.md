# 回帰テスト

Node.js標準のテストランナーで実行します。

```powershell
node --test tests/*.test.cjs
```

階層検証ルール、タブ単位の作業領域キー分離、Web Locks非対応時の重複タブ対策、確認事項数の合算上限、プレビューで選ぶ競合候補と共通変更の合成を確認します。

確認質問の自動テストでは、最大4件の回答候補、候補選択、自由入力、質問ごとの回答必須を確認します。ブラウザーでの手動確認では、依頼全体の質問と提案個別の質問の両方について、候補選択・自由入力・未回答時の送信不可を確認します。回答は再計画・提案の再検討に反映され、変更の適用承認とは別であることも確認します。
