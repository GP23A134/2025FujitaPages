AIチャット設定

AI接続

キーはページを閉じると消去されます。依頼文と選択範囲または全体分析時のクラス情報はOpenAIへ送信され、応答はAPI側に保存されます。利用料はキーのアカウントに請求されるため、信頼できる端末で使用してください。

モデル候補は設定ファイルで管理します。

AIチャットの動作

ONにすると送信前に内容を確認します。確認画面で「これ以降表示しない」を選ぶと、次回以降はOFFになります。

回答

次の依頼から適用します。確認事項への回答中は、その相談で使っているモードを引き継ぎます。

1: 大幅な再編・複数案・価値のないクラスの削除 / 2: 関連する再編・統合 / 3: 一通りの編集操作 / 4: 必要な補助操作 / 5: 明示された変更のみ

数値が小さいほど自由度が高くなります。入力範囲や安全性などの必須ルールは変わりません。

開発者設定

変更はすぐに反映され、自動保存されます。「保存して閉じる」からも保存できます。

AIチャット

送信入力上限

送信入力の上限です。モデルのコンテキスト上限を超えた場合は、API側で受け付けられないことがあります。

出力トークン上限

各値は選択中モデルの最大出力トークン数を超えません。

応答件数上限

件数を増やすと、出力トークン上限に達して回答が完了しない場合があります。

分割・統合

オフにすると分割分析を行いません。1回の送信上限を超える場合は送信できません。

移動先候補を探す

提案自由度にかかわらず、この設定を使って移動先を探します。「全階層を比較」は入力中の全階層を確認し、「階層から候補を検索」は名称が近い上位クラスと中間クラスに候補を絞ります。候補検索では候補外を網羅的に確認しません。

リクエスト処理

分割分析と全範囲の横断確認で、同時に処理するリクエスト数です。初期値は2件です。
