# JavaScript構成

この画面は、因果関係を表す「トリプル」を検索・閲覧する静的ページです。ビルドツールは使わず、`index.html` がJavaScriptファイルを順に読み込みます。

## 全体の流れ

1. `data/output_CCO4KG.js` が、画面に表示する元データを `window.output` に用意します。
2. `data.js` が元データを読み込み、同じ内容のトリプルをまとめて一覧表示用のデータに変換します。
3. `main.js` が検索・クリック・ページ送りの操作を受け取り、`views.js` に画面の更新を依頼します。

## ファイルごとの役割

### `utils.js`

全体から使う小さな共通処理です。HTMLに安全に文字を表示するためのエスケープ、表記ゆれをなくす文字列の正規化、データ行から値を取り出す処理を持ちます。

### `data.js`

`window.output` の元データを読みます。主語クラス・述語・目的語クラスが同じ行を一覧用の1件にまとめます。詳細画面用には、個別の主語・述語・目的語・根拠：ごとのデータも保持し、一覧から選んで表示できます。資料名、都道府県、URL、本文、ステークホルダーの意見も集約します。検索欄で使うクラス名の候補もここで作ります。

### `filters.js`

現在のページ番号、並び替え条件、選択済みのクラス名・都道府県・主語・目的語を覚えます。また、各トリプルが選択中の条件をすべて満たすかを判定します。

### `views.js`

画面を更新する処理です。入力文章に含まれるクラス名の強調表示、結果テーブル、選択中フィルタの表示、ページ送り、列のソート、詳細ダイアログを描画します。

### `main.js`

アプリケーションの入口です。画面が開かれたときに、入力欄、テーブル内のボタン、ページ送り、設定画面、各ダイアログをそれぞれの処理へ接続します。画面初期化の薄いラッパーもここに集約しています。

## 操作と処理の対応

### 検索欄に文章を入力

`views.js` が文章中のクラス名を見つけ、選択できるラベルとして表示します。入力のたびに既存の絞り込み条件は解除されます。

### クラス名・都道府県・主語・目的語をクリック

`filters.js` が選択状態を更新し、`views.js` が条件に合う行だけを再表示します。

### 因果構造検索で主語クラス・述語・目的語クラスを選ぶ

主語側のクラス、述語、目的語側のクラスをそれぞれ条件にして絞り込みます。主語クラスを選ぶと対応する述語が、さらに述語を選ぶと対応する目的語クラスが候補になります。

### 列見出しをクリック

`views.js` が選択された列を基準に並び替えます。繰り返しクリックすると、降順、昇順、並び替えなしの順に切り替わります。

### 「詳細」をクリック

`views.js` が選択したトリプルに関連する資料、本文、因果構造、ステークホルダーの意見をダイアログに表示します。

### 「前へ」「次へ」をクリック

`main.js` がページ番号を変更し、`views.js` が該当ページの100件を表示します。

## 読み込み順

ファイルは次の順で読み込まれます。後ろのファイルは、前に読み込まれたファイルの関数や状態を利用します。

```text
utils.js -> data.js -> filters.js -> structured_search.js -> triple_detail_view.js -> item_detail.js -> views.js -> summary.js -> triple_detail_dialog.js -> main.js
```

画面構造は `index.html`、画面の見た目は `css/`、表示する元データは `data/output_CCO4KG.js` に置いています。画面構造を動的に生成する必要がないため、HTMLテンプレート用のJavaScriptは置いていません。
