# 上位クラスのクエリ結果

`QueryRun all`が生成する上位・中間クラスの階層情報JSONを置きます。`QueryRun all`は基本クエリ結果と階層クエリ結果を取得し、`DataIntegrate`が基本クエリ結果と合わせて統合します。各フォルダーの役割は[クエリ結果README](../README.md)を参照してください。

このフォルダのJSONはクエリ結果です。手動で変更せず、`java/upper-class-querys/`のクエリを`QueryRun all`で再実行して更新してください。実行手順は[Java README](../../../java/)を参照してください。
