# クエリ取得結果

`QueryRun`がSPARQLクエリから取得したJSONを保存します。これらは`DataIntegrate`の入力で、Web表示の元データを更新する際に使います。クエリを再実行すると該当する取得結果が置き換わるため、実行後に差分を確認してください。

| フォルダ | 内容 |
|---|---|
| `base/` | インスタンス、ラベル、クラスに関するクエリ結果 |
| `hierarchy/` | クラスから上位クラスまでの階層に関するクエリ結果 |

`QueryRun all`を実行すると両方を取得します。再取得時は、各フォルダ内の既存JSONが新しい結果に置き換わります。手動で編集せず、必要な場合は`java/querys/`または`java/upper-class-querys/`のクエリを更新して再取得してください。一時`.tmp`ファイルは処理中に使われ、Git管理対象外です。
