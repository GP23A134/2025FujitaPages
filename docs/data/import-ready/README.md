# 読み込み用データ

`class-instance-data.json`は、`data/query-results/base/`にある3つのSPARQLクエリ結果を1つにまとめたデータです。上位クラス・中間クラスの階層は含めず、クラス、インスタンス、所属関係をそれぞれ分けて格納しています。

```json
{
  "classes": [{ "id": "...", "label": "..." }],
  "instances": [{ "id": "...", "label": "..." }],
  "relations": [{ "instance": "...", "class": "..." }]
}
```


IDはクエリ結果のURIをそのまま使用しています。今回のデータにはラベルありクラス229件、ラベルありインスタンス2,315件、所属関係2,314件があります。関係の参照先はすべてこのJSON内に含まれています。

## 例外データ

通常データに含めていない例外は[`exceptions.json`](exceptions.json)にまとめています。

| 種類 | 件数 | 内容 |
|---|---:|---|
| ラベルなしクラス | 1 | クラスID `https://kozaki-lab.jp/REFV-KG/class/st_14` はありますが、ラベルがありません。 |
| クラスなしインスタンス | 1 | `https://kozaki-lab.jp/REFV-KG/data/st_10221_1`（遠藤初子議員）は所属クラスがありません。 |

クラスラベルのクエリ結果にはクラスIDもない空行が1件あります。これはクラスとして登録できるIDがないため、例外ファイルには個別のクラスとして含めていません。
