# 生成TSV

このフォルダには、統合データから生成した上位・中間クラス一覧を置きます。ファイルは手動編集せず、`DataIntegrate`または`ClassDataUpdate`を実行して更新してください。どちらのプログラムでも同じ統合済みクラス分類を基に再生成します。

| ファイル | 内容 |
|---|---|
| `middle-class-list.tsv` | 中間クラスのIDとラベル |
| `top-class-list.tsv` | 上位クラスのIDとラベル |

どちらもUTF-8、タブ区切りで、ヘッダーは`ID`と`ラベル`です。IDは省略せず正式URIで出力し、ID順に並べます。未分類上位クラス`t_0`も一覧に含まれます。
