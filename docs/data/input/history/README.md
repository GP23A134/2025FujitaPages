# クラス分類の更新履歴

`ClassDataUpdate`が分類更新の前後に作るJSONを、このフォルダーへ保存します。

| ファイル名 | 内容 |
|---|---|
| `class-data-before-update-YYYYMMDD-HHmmss-SSS.json` | 更新実行前のクラス一覧と親子関係。全件形式で、復元に使えます |
| `class-update-YYYYMMDD-HHmmss-SSS.json` | 正常に適用された全件入力または差分入力 |

入力の検証に失敗した場合は、統合データを変更せず、入力JSONをこのフォルダーへ移動しません。成功時は更新前スナップショットを保存し、出力完了後に適用済み入力を移動します。

履歴JSONはローカルに保存し、`.gitignore`でGit管理から除外します。長期保管する場合はリポジトリ外にもバックアップしてください。履歴から分類を復元する手順は[クラス分類の更新README](../README.md#変更前へ戻す)を参照してください。
