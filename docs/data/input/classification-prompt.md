# 分類入力TSVを作成するためのプロンプト

次のルールで、分類変更用の2つのTSVを作成してください。

## class-list.tsv

- ヘッダーは `種類<TAB>ID<TAB>ラベル`
- 種類は `top`、`middle`、`class` のいずれか
- 新規クラスはIDを空欄にする
- 既存クラスは完全URIまたは `t_00001`、`m_00001`、`c_00001` の形式で記載する

## class-relation.tsv

- ヘッダーは `子クラスID<TAB>親クラスID`
- クラス間の所属関係を1行ずつ記載する
- 対象クラス・中間クラス・上位クラスのすべてを指定できる
- インスタンスIDは記載しない

入力内容に不明点がある場合は、TSVを生成せず、問題点を箇条書きで示してください。
