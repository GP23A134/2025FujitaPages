# 資料種別の分類依頼プロンプト

次のレビュー用TSVを読み、各文書の「資料種別」と「判定根拠」を分類してください。入力TSVは526件です。

## 分類先

資料種別は、次の10種類から必ず1つ選んでください。

- 議会会議録
- 審査会資料
- 環境アセス資料
- 行政資料
- 事業者資料
- 市民・住民団体資料
- 報道
- Web記事
- 広報・刊行物
- その他

## 判定ルール

1. `input_file`のファイル名に加え、入力資料の内容や一覧情報が与えられている場合はその記載を根拠にします。ファイル名だけで確定できない場合は推測せず「その他」とし、判定根拠に「情報不足」と記載します。
2. 県知事・大臣等の意見書、勧告など、行政機関が発行した文書は、環境アセスメント関連であっても「行政資料」を優先します。
3. 配慮書、方法書、準備書、評価書、およびそれらに付随する環境アセスメント資料は「環境アセス資料」とします。ただし、上記の行政機関発行文書は「行政資料」とします。
4. 審査会・審議会等の会議資料は「審査会資料」とします。会議そのものの議事録は「議会会議録」に該当するかを判定し、審査会資料と混同しないでください。
5. 作成主体・媒体が資料から確認できる場合は、それに基づいて「事業者資料」「市民・住民団体資料」「報道」「Web記事」「広報・刊行物」を選びます。
6. 分類根拠がない場合に、地域名、ファイル番号、保存先などから資料種別を推測してはいけません。

## 出力

- 入力TSVと同じ526行、同じ行順、同じ列を保ったTSVを返してください。
- 既存列の値を変更せず、`資料種別`、`判定根拠`、`確信度`だけを埋めてください。
- `確信度`には「高」「中」「低」のいずれかを記入してください。情報不足で「その他」とした場合は「低」とします。
- `保存されていたフォルダ名`は、フォルダ一覧などの一次情報が入力として提供されている場合だけ記入します。今回のレビューTSVだけでは空欄のままにしてください。
- `graph`、`documentIRI`、`input_file`、`output_file`、`prefecture`、行順を変更しないでください。
- TSV以外の説明やMarkdownコードフェンスは付けず、ヘッダー行を含むTSVだけを返してください。
- 件数が526行であること、入力行がすべて出力に一度ずつ含まれることを確認してから返してください。

入力ファイル: `input/integration/documents-review.tsv`

分類結果は、確認後に`input/integration/documents-classified.tsv`として保存し、次の統合処理への入力にします。

このレビューTSVには原則としてファイル名等の一覧情報しかありません。文書本文や権威あるファイル一覧がない行は、無理に断定しないでください。
